## 项目简介

这是一份关于高三宿舍的可漫游数字空间记录。项目保留真实扫描中的床位、过道、家具、床单花纹与生活痕迹，让人能在浏览器中重新进入、走动和观察这间宿舍。

**项目制作时间：2026 年。** 这是一项个人空间记录项目。

## iPad Pro 空间扫描来源

空间来自使用 iPad Pro 对真实宿舍进行的扫描。发布版本使用已确认可运行的 GLB 漫游模型，贴图内嵌于模型中；原始 GLB / OBJ / USDZ 档案、原始照片、深度数据、聊天附件及扫描备份均不随仓库发布。

## AI-assisted reconstruction（AI 辅助重建）

AI 协助完成扫描素材检查、浏览器展示、少量孤立碎片筛除、基础缺口背衬以及漫游交互代码。本次发布沿用已确认版本，未采用后续深度重建实验中的替代床架、拟合墙面或重塑床品。

它仍是扫描驱动的数字记录：细杆、门窗及被遮挡区域可能有缺损，纹理保留了扫描时的日光。夜晚模式用于调整观看氛围。模型并非建筑测绘或无缺陷的完整复原。

## 操作方法

| 操作 | 电脑 | 手机 / 平板 |
| --- | --- | --- |
| 行走 | WASD | 左下触屏摇杆 |
| 环顾 | 按住鼠标拖动；或点击“鼠标环顾”，Esc 退出 | 在场景右侧拖动 |
| 调整视线 | 方向键 | 拖动画面 |
| 返回 | “回到入口” | “回到入口” |
| 俯视 | “整体俯视”，拖动旋转、滚轮缩放 | “整体俯视”，触控旋转、缩放 |
| 昼夜 | 点击“白天 / 夜晚” | 同左 |
| 回忆 | 点击场景光点或“回忆” | 同左 |

回忆卡片默认“待补充回忆”。填写内容只存于当前浏览器的 localStorage，不上传 GitHub 或服务器；可导出备份。不同设备及不同站点地址不会自动同步。

## 本地运行与更新

使用 Node.js 22.13 或以上版本：

```sh
npm ci
npm run dev
```

打开终端提示的 `/jiedong-no1-2024-dorm/` 地址。

```sh
npm run check
npm run build
npm run preview
```

GitHub Pages 使用 `main` 分支的 `docs/` 目录。更新代码后重新构建，并将源代码和 `docs/` 一并提交、推送。
